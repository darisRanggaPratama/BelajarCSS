# Stickman Motion Studio

Demo animasi stickman interaktif menggunakan HTML5, CSS3, SVG inline, dan JavaScript native tanpa framework atau library eksternal.

## Menjalankan

1. Simpan `index.html`, `style.css`, dan `script.js` dalam folder yang sama.
2. Buka `index.html` menggunakan browser modern.
3. Klik tombol **Dance**, **Run**, atau **Jump**. Pintasan keyboard juga tersedia: `1` = Dance, `2` = Run, `3` = Jump, `Esc` = kembali ke kondisi diam.

## Struktur file

- `index.html` — struktur halaman, kontrol, dan karakter SVG.
- `style.css` — tema visual, responsivitas, efek latar, dan keyframes animasi.
- `script.js` — pergantian mode, loop `requestAnimationFrame`, partikel, dan lintasan lompatan.

Tidak memerlukan proses build, server, ataupun dependensi eksternal.
